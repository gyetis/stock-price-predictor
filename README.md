# Stock Price Predictor

Web app project that uses OpenAI models to generate a report based on stock tickers.

## Getting Started

Install the dependencies and run the project

```
npm install
npm start
```

Once you see `Server running at http://localhost:3000`, please go ahead and click on the link or open it on your preferred browser.

**Important Note: This app does not live on a server or website. This is just to play with OpenAI models within a HTML page.**

**Disclaimer: This is not real financial advice.**
