# Stock Price Predictor

Web app project that uses OpenAI models to generate a report based on stock tickers.

## Prerequests

You are required to have a Massive account (https://massive.com) and a Google AI Studio account (https://aistudio.google.com). If you already have a Google acount, this should automatically direct you to the platform.

```
1. Clone the repository.
2. Copy the example environment file:
   `cp .env.example .env`
3. Once you sign-in and login to Massive account, go to Dashboard by clicking the Dashboard button on top-left corner.
4. Find 'Keys' on the left side, and it will show the Default API key. Copy this key.
5. Open `.env` that you created on step 2 and copy your personal API key to the relevant variable.
6. Once you sign-in and login to Google AI Studio, go to Dashboard by clicking the Dashboard button on mid-left side.
7. The menu should show you a free tier key. Copy this key.
8. Open `.env` that you created on step 2 and copy your personal API key to the relevant variable.
```

## Getting Started

Install the dependencies and run the project

```
npm install
npm start
```

Once you see `Server running at http://localhost:3000`, please go ahead and click on the link or open it on your preferred browser.
